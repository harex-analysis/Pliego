# Seguridad de Pliego

Envía los avisos de seguridad por **Security → Report a vulnerability** en el repositorio público de Pliego cuando esté habilitado. Incluye la versión de Pliego, la versión de Windows y los pasos para reproducir el problema con material de prueba que puedas compartir.

Evita adjuntar cómics privados, rutas que identifiquen a usuarios, credenciales y magnets privados. Para fallos de uso sin impacto de seguridad, usa Issues.

La versión publicada más reciente recibe las correcciones. Los avisos de dependencias y la lista de binarios incluidos en el paquete se revisan por separado. Consulta [los componentes de terceros](THIRD-PARTY.md) y las versiones fijadas en el proyecto.
